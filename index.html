Recortar conversación de WhatsApp

Pega los mensajes que marcan el inicio y el final. El sistema encontrará el fragmento automáticamente.

1. Selecciona tu archivo ZIP

Selecciona el archivo exportado desde WhatsApp.

Seleccionar archivo ZIP

2. Define el inicio y el final

Copia y pega un mensaje completo o una parte de él. El sistema lo buscará en la conversación.

3. Vista previa del fragmento

Se muestran hasta 10 mensajes como muestra.

4. Generar nuevo ZIP

Se conservará el texto del rango seleccionado y los archivos multimedia identificados.

Privacidad: el archivo se procesa en tu navegador. No se envía a ningún servidor. Necesitas Internet para cargar la librería ZIP. Mantén la página abierta durante el proceso.
