Recortar conversación de WhatsApp

Selecciona un rango de mensajes y crea un ZIP con ese fragmento.

1. Selecciona la exportación

Carga el ZIP exportado desde WhatsApp.

Seleccionar archivo ZIP

2. Define el rango

Los números siguen el orden de los mensajes.

3. Vista previa

Se muestran hasta 8 mensajes de ejemplo.

4. Genera el ZIP

Se incluirán el texto seleccionado y los archivos multimedia identificados.

El procesamiento se realiza en tu navegador. No se envía la conversación a ningún servidor. Necesitas conexión a Internet para cargar la librería ZIP. Mantén la página abierta durante el proceso.
