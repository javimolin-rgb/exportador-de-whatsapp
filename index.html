Recortar conversación de WhatsApp

Selecciona exactamente qué parte de tu conversación quieres conservar.

1. Selecciona el ZIP

Sube el archivo que exportaste desde WhatsApp.

Seleccionar archivo ZIP

2. Selecciona el fragmento

Pega el texto de los mensajes que delimitan el fragmento. Puedes pegar el mensaje completo o una parte suficientemente específica para identificarlo.

3. Comprueba el fragmento

Vista previa de los primeros y últimos mensajes del rango.

4. Exportar

Se creará un ZIP con el texto seleccionado y los archivos multimedia que puedan identificarse.

El procesamiento se realiza en tu navegador. No se envía tu conversación a ningún servidor. Necesitas conexión a Internet para cargar la librería ZIP. No cierres la página durante la exportación.
